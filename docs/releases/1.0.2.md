# Yoshi's Story Recomp 1.0.2

Patch release adding the controller settings overlay and preserving the separate
desktop settings windows. The Windows tag is `windows-v1.0.2`.
The [GitHub release](https://github.com/TK22-26/yoshis-story-recomp/releases/tag/windows-v1.0.2)
records publication status, the exact source revision, package inventory, and checksums.

## Settings

Start + Back / Select opens Video, Audio, Controls, and About inside the game
window, with the game dimmed behind the settings. Either button order works;
release both before using the shortcut again. Esc and a Back / Select tap also
open the overlay. Start alone retains its normal game action.

Desktop menu settings entries continue to open separate native windows at the
requested tab. Both views share the settings, controller navigation, and help.
Large plain LB / RB labels flank the tabs. D-pad or left stick moves focus;
A selects or adjusts; B goes back. Quit beside Return to game asks for
confirmation with Cancel selected by default, and B / Esc cancels.

Settings pause the game and audio while preserving a previous manual pause.
The overlay stays inside the game window in fullscreen and after using a
desktop settings window. UI images render through the game's graphics backend.

## Verification

- Eight local C++ checks, including shortcut press order, held inputs, controller
  navigation with a virtual SDL gamepad, sliders, binding cancellation, tab
  switching, credits scrolling, pause/resume, disconnect recovery, native
  settings windows, and Quit confirmation. The shortcut check also runs in
  ROM-free CI alongside the existing runtime checks.
- Ten release integrity regressions covering the package allowlist, modified
  files, stale or dirty executable identities, documentation, and executable
  icon/subsystem requirements.
- Windows 11 / Direct3D 12 smoke checks for the overlay in windowed and fullscreen
  modes, shared About artwork, separate desktop settings, returning to the
  overlay after closing a native window, and cancelling/confirming Quit.
- The portable ZIP is checked with the [first-launch procedure](maintenance.md):
  extraction to a Unicode path, launch from another working directory, native
  ROM selection and cancellation, invalid ROM rejection, local ROM import,
  subsequent startup, and in-game ROM picker ownership/cancellation.
- Release verification checks the clean source revision, exact patched
  dependencies, executable version, embedded egg icon, program/document
  allowlist, every packaged file digest, and the complete ZIP checksum.

No ROM, game assets, saves, logs, or symbols are included. Existing data should
be copied into a fresh extraction when updating. The platform and gameplay
limits in [1.0.0](1.0.0.md) still apply; these checks do not establish a complete
campaign playthrough or qualification on additional renderers or platforms.
