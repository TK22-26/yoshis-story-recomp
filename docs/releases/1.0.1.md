# Yoshi's Story Recomp 1.0.1

Replacement for the withdrawn Windows 1.0.0 release, approved by the maintainer
after testing the corrected startup flow. The old release and its downloads
were deleted; its tag remains unchanged. The Windows tag is `windows-v1.0.1`.
The [GitHub release](https://github.com/TK22-26/yoshis-story-recomp/releases/tag/windows-v1.0.1)
records publication status and the exact package inventory and checksums.

## First-launch correction

The obsolete display-settings launcher has been removed. An empty installation
opens the native Windows file picker, with the project egg icon. The player can
select their own USA ROM at any path, in z64/n64/v64 byte order. The app validates
the complete image against the runtime's expected hash before atomically saving
a local z64 copy in `data/`. The original file is never modified. Cancel exits;
an incorrect ROM produces an error and returns to selection. Later launches use
the validated local copy directly. Game > Select ROM opens the same picker as an
owned dialog while the game is paused; Cancel restores play without changing data.

The executable now uses the Windows GUI subsystem and embeds the approved egg
PNG as an icon resource, plus file/product version metadata. Explorer launches it
without a console. Diagnostics go to `data/runtime.log`, replaced on each launch;
explicit stdout/stderr redirection and `--build-info` still work for tools.

## Verification

- Six C++ checks, including synthetic ROM byte-order normalization, Unicode paths,
  size/header rejection, atomic replacement, and preserving existing data when
  a destination is locked or a write fails. No game data is used by these tests.
- Ten release regression tests, including rejection of a console executable or
  a build missing the approved egg icon. Actual release verification also checks
  that Windows can extract an icon from the packaged executable.
- Windows 11 / Direct3D 12: first launch from an empty data directory, Cancel,
  rejection of a full-size invalid ROM, selection from a path with spaces and an
  accented character, boot into the game, subsequent direct launch, and in-game
  ROM selection/cancellation. The copied ROM matches the local source checksum.
- The actual portable ZIP was extracted into a fresh folder containing accented
  and Japanese characters, then launched from `C:\Windows` with no data-directory
  or launcher overrides. Verified first-launch selection/cancellation, v64 and
  n64 imports with matching normalized checksums, direct subsequent startup,
  readable diagnostics, and the egg extracted from the executable by Windows.
  The in-game picker owns/disables its game parent and re-enables it on return.
- Package allowlist: 14 programs, 39 documents, and an empty data directory.
  No ROM, game assets, saves, logs, generated source, or symbols are included.
  Future builds must repeat [the first-launch procedure](maintenance.md).

The broader gameplay and platform limits in [1.0.0](1.0.0.md) still apply. These
startup corrections do not establish a complete campaign playthrough or extend
qualification to Windows Vulkan, native Windows 10, or the full Linux fork.
