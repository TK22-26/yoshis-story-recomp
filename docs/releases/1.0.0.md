# Yoshi's Story Recomp 1.0.0

The maintainer approved the Windows build and requested release preparation.
This record describes the initial Windows release candidate; publication is a
separate step. The GitHub release's draft/public state is authoritative.

## Scope

Windows x64 and the original USA ROM. Direct3D 12 is the default renderer;
Vulkan is the fallback. The prebuilt game needs the user's ROM at runtime but
does not compile anything on first launch. Its ZIP includes the required host
DLLs, Microsoft Visual C++ runtime, setup instructions, changelog, and notices.
No ROM, extracted game assets, saves, recordings, generated source, or symbols
are included. The embedded interface artwork is listed in
[assets/README.md](../../assets/README.md).

## Verification retained

- Windows 11 / Direct3D 12 startup, EEPROM save creation, keyboard/controller
  input, restart, pause/resume, and mute/unmute.
- Windowed, borderless window, and borderless fullscreen modes, including
  physical-monitor bounds and restoring the previous window size/style.
- Native settings-window ownership, disabled parent while a dialog is open,
  DPI-aware text and diagrams, tooltip padding, and the versioned About screen.
- Controller choice persists after restarting. Virtual SDL gamepads exercise
  device selection, input isolation, unplug/reconnect, and actual axis events.
- Mapping tests cover signed axes, proportional input, dead zones, legacy
  settings migration, one controller input per action, and saved mappings.
- Rendered Xbox, DualShock 3/4, and DualSense glyphs checked against the supplied
  reference. This does not claim physical testing of every controller model.
- Storybook seams reproduced in the upstream Linux AppImage; the focused
  correction tested on Windows and upstream source under Ubuntu 26.04 / WSL2 /
  Vulkan. Upstream report: https://github.com/damobeanrod/yoshis-story-recomp/pull/1
- Package verification checks the allowlist, documentation, ZIP integrity,
  source/version identity, whole-archive checksum, and every file digest.
  Release metadata tests reject modified files and mismatched build identities.

## Remaining limits

This is not a complete campaign playthrough. Windows Vulkan and the complete
Windows fork on Linux have not been requalified. Native Windows 10, additional
GPU vendors, and physical PlayStation controllers need broader playtesting.
Anti-aliasing changes require a restart. Controllers without a serial number or
stable path are remembered by player slot or enumeration order.

The `.inventory.json` attached to the release records the exact source commit,
dependency revisions, patch hashes, and packaged file hashes. The neighboring
`.sha256` file identifies the ZIP. These generated identities are kept with the
draft so rebuilding cannot silently change a published artifact.
