Yoshi's Story Recomp 1.0.1 - Windows x64

1. Extract the entire ZIP into a writable folder.
2. Open yoshis_story_recomp.exe.
3. Choose your own USA Yoshi's Story ROM in the file picker (.z64, .n64, or .v64).
   You do not need to rename or move it. Cancel exits the app.
4. The app verifies it, keeps a private local copy in data/, and starts the game.
   Later launches go straight into the game. Use Game > Select ROM to choose again.

Video > Video settings opens the display settings while playing.
There is no startup settings launcher or console window. Diagnostics are saved
in data/runtime.log and replaced on each launch.

Keep all DLLs beside the executable. The Microsoft Visual C++ runtime is
included. No Git, Python, Visual Studio, WSL, or first-run compilation is needed.

Windows 10 version 1803 or newer, x64, and a compatible Direct3D 12 or Vulkan
GPU/driver are required. Windows 11 with Direct3D 12 was tested.
Only the USA ROM is supported. No ROM, extracted game assets, personal saves,
recordings, generated source, or debug symbols are included.

Controls menu: select your controller and rebind inputs.
Esc / controller Back: settings. F1: show/hide the menu.
Pause: pause/resume. Ctrl+M: mute/unmute. Alt+F4: quit.
F11 / Alt+Enter: toggle borderless fullscreen.

The data folder holds your ROM, saves, and settings. Back it up before updating.
Extract updates into a new folder and copy your existing data folder across.
Do not overwrite personal files with a release's empty data folder.
